# Field Notes Redesign — Cycle 1 (Foundation + Hero + Prism) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Establish the warm-light editorial visual system (tokens, typography, IA skeleton) and ship the new Hero and the Prism case study — the section that proves out the site's figure/metric/diagram grammar — to a shippable standard.

**Architecture:** Next.js 15 App Router site, no backend. New design tokens live in `globals.css`/`layout.tsx`. A new `CaseStudy`/`Metric`/`Figure` data shape is added to `src/lib/data.ts` alongside the existing exports (untouched). Three small shared presentational components (`SectionLabel`, `ProjectMetric`, `Figure`) back a bespoke `PrismCaseStudy` component (not a generic template — Cycle 2's other three case studies will each get their own composition). Two hand-built SVG diagrams (redrawn, not reused images) cover Prism's request flow and infrastructure topology; five real screenshots are copied in from the local `LLM Gateway` repo.

**Tech Stack:** Next.js 16 / React 19 / TypeScript / Tailwind CSS v4 / Framer Motion / `next/font/google` (Geist, Geist Mono — already loaded, no new font dependency). No test framework is installed in this repo (`package.json` has only `dev`/`build`/`start`) — see Global Constraints for how verification works instead.

**Spec:** `docs/superpowers/specs/2026-09-09-field-notes-redesign-design.md`

## Global Constraints

- Palette (exact, from spec): background `#F6F5F0`, primary text `#171715`, secondary text `#6A6963`, borders `#D8D6CF`, subtle surface `#ECEAE4`, primary accent `#355C8A`, secondary/annotation accent `#A54A42`. One dominant accent (blue) — the red is reserved for figure labels and small research metadata only, never given equal visual weight.
- Type: sans (`Geist`) for headings/body/nav, mono (`Geist Mono`) only for dates, figure labels, metadata, stack tags, metrics — never body copy. No serif. Tighter tracking on large headings.
- **New/rewritten files in this plan use the Tailwind token utilities** generated by `globals.css`'s `@theme inline` block (`bg-background`, `text-foreground`, `text-muted`, `bg-surface`, `border-border`, `border-border-strong`, `text-accent`, `text-accent-secondary`, `font-sans`, `font-mono`) — not hardcoded hex classes. This differs from older untouched components in this repo (e.g. `About.tsx`, `Projects.tsx`) which hardcode hex directly; that's their existing, unchanged convention and out of scope here. Inside raw SVG `fill`/`stroke` presentation attributes, use local hex constants matching the token values exactly (Tailwind classes don't reach SVG presentation attributes) — `font-family` on SVG `<text>` can use `var(--font-geist-mono)` directly, matching the existing `PrismFlowDiagram.tsx` precedent already shipping on this site.
- No light/dark toggle, no gradients/glassmorphism/glow/particles/typewriter/bouncing or floating motion. Framer Motion only for opacity/vertical-reveal, 150–450ms. Respect `prefers-reduced-motion` (handled globally in Task 1).
- **Every number in `caseStudies` data must trace to a verified source.** The Prism entry in Task 2 is transcribed directly from `/Users/naman/Developer/LLM Gateway/README.md` and `docs/architecture.md` — do not round, simplify, or "clean up" any figure.
- **No test framework exists in this repo.** Each task's verification step is: (a) `npx tsc --noEmit` from the repo root passes with no errors, (b) `npm run dev` and a specific, described manual check in the browser at `http://localhost:3000`, and the final task additionally runs `npm run build`. This is the adaptation of the usual write-test/run-test cycle to a project with no test harness — do not invent a testing library as part of this plan.
- **Do not run `git push`.** Commit locally after each task as instructed; this branch should not reach `origin/main` (which auto-deploys to production) until the user has reviewed it, since the page will be in a deliberate mixed state (new light Hero/Selected Work above old, untouched dark "Systems Notebook" sections) until Cycle 2 ships.
- Cycle 1 does not touch `About.tsx`, `Skills.tsx`, `Experience.tsx`, `Publications.tsx`, `SideQuests.tsx`, `Contact.tsx`, `JourneyMap.tsx`, or their dependencies — those are Cycle 2. The one exception is a one-line filter in `Projects.tsx` (Task 10) to stop Prism appearing twice now that it has its own case-study section.
